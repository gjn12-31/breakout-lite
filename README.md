# Breakout-Lite · 打砖块

原生 HTML + CSS + JavaScript 写的打砖块小游戏，零依赖，单个 `index.html` 即可运行。

## 玩法

- 鼠标移动或 ←→ 键控制挡板，点击/按任意键发球，空格暂停
- 打光所有砖块进入下一关，每关多一排砖、球速更快
- 顶部两排是双血砖，分数更高
- 连续击碎砖块有连击加分，每 5 连击挡板会变宽一点
- 共 3 条生命

## 在线试玩

👉 https://gjn12-31.github.io/breakout-lite/

## 运行

直接用浏览器打开 `index.html` 即可。

## 技术说明

- Canvas 渲染 + `requestAnimationFrame` 游戏循环
- 挡板击球位置决定反弹角（最大 ±60°），可以打出弧线球
- 砖块碰撞用重叠量判断反弹轴，避免穿砖抖动
- 球带拖尾效果，关卡/砖块参数集中在 `initLevel()` 里，方便调整难度
