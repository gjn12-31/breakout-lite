# Breakout-Lite · 打砖块

原生 JavaScript 编写的打砖块小游戏，零依赖、无构建步骤。使用 ES Modules 做了模块化拆分，包含道具系统、粒子特效、合成音效等完整玩法。

## 在线试玩

👉 https://gjn12-31.github.io/breakout-lite/

## 玩法

- 鼠标移动或 ←→ 键控制挡板，空格 / 点击发球
- 打光所有可击碎的砖块进入下一关，共 6 关，每关布局不同、球速更快
- 砖块有 1~3 血三种，**带斜纹的灰色砖不可摧毁**，只作障碍
- 连续击碎砖块累计连击，有额外加分
- 砖块被击碎有概率掉落道具，用挡板接住生效：

| 道具 | 效果 |
|---|---|
| E | 挡板加宽（限时） |
| M | 分裂成多球 |
| L | 挡板加装激光炮，空格发射（限时） |
| S | 球减速（限时） |
| T | 粘性挡板，接住球可调整角度再发射（限时） |
| + | 加一条命 |
| - | 挡板变窄（是陷阱！） |

- 共 3 条生命，最高分保存在浏览器本地

## 本地运行

因为是 ES Modules，需要通过 HTTP 访问（直接双击打开会跨域报错）：

```bash
cd breakout-lite
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 项目结构

```
breakout-lite/
├── index.html          # 页面骨架 + HUD + 覆盖层
├── css/
│   └── style.css       # 界面样式
└── js/
    ├── main.js         # 入口：装配 DOM 与游戏实例，启动主循环
    ├── game.js         # 状态机、实体调度、碰撞与计分
    ├── entities.js     # 挡板 / 球 / 砖块 类
    ├── powerup.js      # 道具类型与掉落逻辑
    ├── levels.js       # 6 个关卡的字符画布局定义
    ├── particles.js    # 粒子特效与漂浮得分文字
    ├── audio.js        # WebAudio 合成音效（无音频素材）
    ├── input.js        # 键盘 / 鼠标 / 触摸统一输入
    ├── config.js       # 全部可调参数
    └── utils.js        # 通用工具函数
```

## 技术要点

- **状态机**：menu / ready / playing / paused / levelup / gameover 六态流转
- **反弹角控制**：挡板击球位置决定反弹角（最大 ±60°），粘性挡板可主动蓄角度
- **碰撞检测**：砖块碰撞按两轴重叠量判断反弹方向，避免贴边抖动
- **合成音效**：全部音效用 WebAudio 振荡器实时合成，仓库不含任何音频文件
- **特效**：粒子爆裂、球体拖尾、屏幕震动、漂浮得分
- **可配置**：关卡、球速、道具掉率、道具时长等全部集中在 `config.js` 与 `levels.js`，改一处即生效
